# Usabilitat
  ## Visibility of System Status
   * O menu de navegaçao mostra onde o utilizador está no momento e mostra todas as outras opçoes de navegaçao pela página web.
  ## Match Between the System and the Real World
   * O utilizador consegue compreender facilmente tudo o que está escrito devido a termos uma linguagem de fácil compreençao na nossa página web, em alguns botoes temos também emojis para uma fácil comprençao.
  ## User Control and Freedom
   * Fora da parte de admin da página web o utilizador tem sempre uma saida fácil, agora quando entramos na parte de admin e mais especificamente na aba de produtos se for inserir um produto novo ma usar o botao de voltar a trás o utilizador volta para a página inicial de admin, nas outras abas de admin esse problema já nao ocorre.
  ## Consistency and Standards
   * A nossa página web na nossa opiniao tem os botoes, açoes e o design consistentes para uma melhor experiencia do utilizador.
